    Is this really off record?

    Only the sealed enclave can read it

    Your browser checked signed proof from Intel and NVIDIA that the AI runs inside locked hardware. Nobody can look inside it, NEAR AI's own staff included.

    Scrambled before it left your device

    Your message was locked to that enclave's key right here. Everyone in between, prompt20 and NEAR AI included, only passed along gibberish. Tap the boxes below to see exactly what each one got.

    The reply came from that enclave

    The enclave signed every reply. If anyone changed a single letter on the way, this would turn red.

    What it cannot promise. Others can see that you used it, when, and how much you sent. The proof shows which program runs in the enclave; it cannot show that the program keeps no copy. One key covers every copy of a model's enclave, so the proof names the deployment, not one machine. Your history stays in this browser until you delete it.

    The six checks behind this

    1. Real secure hardware
    2. Proof made for this run
    3. Key matches the enclave
    4. Locked before sending
    5. Reply signed by it
    6. Display matches proof

        • The free demo sends through prompt20.com, which adds a demo key. It carries only ciphertext and sees your IP; NEAR AI then sees prompt20.com's address in place of yours.
          • 
    
        • You trust this page's code (anyone can confirm it matches the public repository with npm run check-live) and NEAR AI's key handling. Attestation proves what ran, not that nothing is logged.

        • Intel's and NVIDIA's evidence is checked in this page. prompt20.com only relays Intel's signed collateral and NVIDIA's verifier, which send no CORS headers.

        • CPU and GPU proofs are linked only by the shared nonce.

        • Model weights are named by a label in NEAR AI's deploy file. The engine is pinned; the weights are not measured.
